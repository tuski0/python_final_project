# 도서 대여 CLI 프로그램

### 저장소 클론

```
git clone git@github.com:tuski0/python_final_project.git
```

### 의존성 설치

```bash
uv sync
```

### 실행 방법

```bash
source .venv/bin/activate
uv run main.py
```
